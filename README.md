# 🎓 Learn Bash Scripting by Building Five Programs 🎉

Hello! This is the project I completed to learn Bash scripting. During the process, I built five programs that helped me understand how to combine terminal commands and programming logic to create useful programs and automate tasks. 🖥️💡

---

## 🌟 What I Learned

1. **Basic Bash Syntax**:
   - How to write scripts in Bash using the `#!/bin/bash` interpreter.
   - Using comments to document code.

2. **Variables and User Interaction**:
   - Declaring and using variables to store data.
   - Asking for user input with commands like `read` and displaying personalized results.

3. **Conditionals and Logic**:
   - Using structures like `if`, `elif`, and `else` to make decisions based on conditions.
   - Understanding how comparisons and operators work in Bash.

4. **Loops and Automation**:
   - Using loops to repeat tasks automatically.
   - Creating timers and handling command-line inputs.

5. **Random Number Generation**:
   - Using `$RANDOM` to generate random values and apply them in different scenarios.

6. **Modularity**:
   - Breaking down a program into smaller scripts that can be executed from a main file.
   - Calling other scripts within a main program.

---

## 📂 Programs I Built

1. **Questionnaire**:
   - This program asks three questions: your name, where you are from, and your favorite programming website. It then combines the answers into a personalized message.

2. **Countdown Timer**:
   - A timer that counts down from a number provided as input.

3. **Bingo Number Generator**:
   - Generates a random number between 1 and 75 and associates it with its corresponding bingo letter (B, I, N, G, O).

4. **Fortune Teller**:
   - Although similar to the Bingo Number Generator, this program demonstrates how ideas can be reused and adapted for different purposes.

5. **Main Program**:
   - A script that runs all the other programs in order. This taught me how to organize and execute multiple scripts from a main file.

---

## 🏁 How I Ran the Project

1. Created a main file to execute the other four programs.
2. Ensured each script had execution permissions (`chmod +x`).
3. Ran the main file from the terminal, which executed each program in sequence.

---

## 🤔 What Was the Most Interesting?

- Learning to use `$RANDOM` to create a number generator was incredibly fun.
- Seeing how conditions (`if`, `elif`) make a program flexible and responsive to different inputs was a big takeaway.
- Writing a modular program that connects all the scripts together was very rewarding.

This project helped me understand how Bash scripting works and how to use it to automate tasks. I’m excited to keep learning and exploring more possibilities with Bash! 😊
